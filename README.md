# 星河邮局 · 把心愿交给流星

一个纯 HTML / CSS / JavaScript 的互动许愿网站，可直接部署到 GitHub Pages。

## 功能
- 深蓝紫色星空、闪烁星星、随机流星和飘落花瓣
- 点击“让流星划过”即可看到流星动画
- 输入 1–9 改变许愿瓶里的星星数量与光效
- 输入普通文字并点击“许下心愿”，触发流星动画并展示心愿
- 输入 `MY-1125` 进入“李梦瑶”专属祝福界面
- 祝福逐句出现，最后显示一封温柔的小信
- 手机与桌面布局适配；支持减少动态效果的系统设置

## 本地预览
双击 `index.html`，用浏览器打开即可。

## 发布到 GitHub Pages
1. 在 GitHub 新建一个仓库。
2. 上传 `index.html` 和 `README.md` 到仓库根目录。
3. 进入 **Settings → Pages**。
4. 选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。
5. 等待部署完成，使用 GitHub Pages 显示的网址访问。

## 修改彩蛋口令
在 `index.html` 搜索 `const SECRET_CODE='MY-1125';`，替换成自己想用的口令。

## 修改祝福内容
搜索 `class="messages"` 和 `class="letter"`，即可编辑祝福句子与信件。

## 注意
口令只用于制造前端惊喜，并非真正的安全验证。网站源代码公开后，访问者可以查看口令。
