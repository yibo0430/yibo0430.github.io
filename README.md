# 一念成仙 · Cultivation Survivors

一个使用原生 HTML、CSS、JavaScript 和 Canvas 制作的像素风修仙幸存者肉鸽原型，可直接部署到 GitHub Pages。

## 文件结构

- `index.html`：页面结构与界面
- `style.css`：像素仙侠风 UI、响应式布局、手机控制样式
- `game.js`：游戏循环、英雄、战斗、技能、宝箱、Boss、音效逻辑

## 本地运行

直接打开 `index.html` 即可游玩。若浏览器限制本地资源，可在项目目录启动一个静态服务器，例如：

```bash
python -m http.server 8000
```

再打开 `http://localhost:8000`。

## 部署到 GitHub Pages

1. 新建 GitHub 仓库。
2. 上传这三个文件到仓库根目录。
3. 进入 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 `Deploy from a branch`。
5. 选择 `main` 分支和 `/ (root)`，保存后等待部署完成。

## 操作

- 电脑：WASD / 方向键移动，空格释放主动技能，按住鼠标左键并拖动进行瞄准。
- 手机：左下角虚拟摇杆移动；按住右下角「瞄准」并拖动控制攻击方向；点击主动技释放技能。
- 升级：选择一项机缘；每张技能卡的刷新按钮在本次升级中只能使用一次。

## 原型包含

- 4 位可选英雄，各有不同基础属性、主动技能和视觉配色
- 自动攻击、按住瞄准线、虚拟摇杆与多点触控基础支持
- 无限延展的跟随镜头地图
- 随机经验宝箱 / 道具宝箱
- 技能叠加、法宝、灵宠、全屏攻击、组合觉醒效果
- 3 / 6 / 10 分钟 Boss 提示与 Boss 血条
- Web Audio 合成背景旋律，Boss 战切换更紧张的节奏（无需外部音频文件）

## 说明

这是可玩的原型版本，所有图形均由 Canvas 绘制，英雄头像使用系统 Emoji 作选择界面图标。音频需要用户先点击开始游戏后由浏览器启用。可继续扩展精灵图、存档、更多关卡和完整平衡性。
